Hotel Booking Website with AI Chatbot

A full-stack Hotel Booking Website developed using PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap. This project allows users to browse hotel rooms, view facilities, make bookings, manage profiles, and interact with an AI-powered chatbot for assistance.

Features
User Registration & Login
Hotel Room Booking System
Room Details & Facilities
AI Chatbot Assistant
Contact Form Integration
Payment Pages
Booking Confirmation
Responsive User Interface
Admin Database Management using phpMyAdmin
Technologies Used
PHP
MySQL
HTML5
CSS3
JavaScript
Bootstrap
XAMPP
Project Structure
/inc           - Database and common PHP files
/images        - Website images
/ajax          - AJAX requests
/chatbot       - AI chatbot functionality
/phpmailer     - Email functionality
Installation
Install XAMPP
Move project folder to:
C:\xampp\htdocs\
Start Apache and MySQL from XAMPP
Create a database in phpMyAdmin
Import SQL tables or create required tables
Open browser and run:
http://localhost/project-folder-name
