# Hotel Booking Website with AI Chatbot

A full-stack Hotel Booking Website developed using PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap. This project allows users to browse hotel rooms, check facilities, make bookings, and interact with an AI-powered chatbot assistant.

---

## Features

- User Registration and Login
- Hotel Room Booking System
- Room Details and Facilities
- AI Chatbot Assistant
- Contact Form
- Payment Pages
- Booking Confirmation
- Responsive Design
- Database Management using phpMyAdmin

---

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- XAMPP

---

## Project Structure

/inc        - Database and common PHP files  
/images     - Website images  
/ajax       - AJAX request handling  
/chatbot    - AI chatbot functionality  
/phpmailer  - Email functionality  

---

## Installation Steps

1. Install XAMPP
2. Move the project folder into:

C:\xampp\htdocs\

3. Start Apache and MySQL from XAMPP
4. Create a database in phpMyAdmin
5. Import or create the required tables
6. Run the project in browser:

http://localhost/project-folder-name
